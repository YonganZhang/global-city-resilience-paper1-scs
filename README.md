# Global City Infrastructure Resilience Index (GCIRI)

This repository accompanies the manuscript *City-scale infrastructure
resilience assessment using a multi-LLM parliament framework* submitted to
*Sustainable Cities and Society*.

It contains the model-related code used for Bayesian indicator fusion,
city-scale physical-risk downscaling, calculation of the absorption loss,
response deficit, recovery capacity and final GCIRI, together with the
statistical functions used for the supporting ablation, peer-control,
repeatability, parameter-sensitivity and external-ranking analyses. The exact
executable R1, R2 and Consul prompt builders and the model specifications are
also included.

The release does not contain study data, 50-city results, model outputs,
figures, plotting code, credentials, API logs or environment files.
